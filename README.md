# Smart Recognizer для Jellyfin

Плагин для Jellyfin 12.4+, который распознаёт фильмы и сериалы по «грязным» именам файлов и папок и собирает метаданные из **TMDb, Кинопоиска, OMDb (IMDb) и TVDB**. Если правила разбора не справились, можно подключить **ИИ** как запасной вариант.

Встроенный парсер Jellyfin часто ошибается на таких именах:

| Имя на диске | Что получается |
|---|---|
| `Темный.рыцарь.The.Dark.Knight.2008.BDRip.1080p.mkv` | «Тёмный рыцарь» / «The Dark Knight», 2008 |
| `Тёмный рыцарь (The Dark Knight) 2008 BDRip [Дубляж, iTunes].mkv` | два названия, 2008, теги озвучки |
| `Сериалы/Кухня/Сезон 2/Кухня - Серия 3.mkv` | «Кухня», S02E03 (встроенный парсер Jellyfin 12.4 читает это как S07E05) |
| `Сериалы/Метод/2 сезон/05 серия.mkv` | «Метод», S02E05 |
| `Breaking.Bad.S01E01-E02.720p.WEB-DL.mkv` | «Breaking Bad», S01E01–E02 |
| `[SubsPlease] Frieren - 30 (1080p) [ABCD1234].mkv` | «Frieren», серия 30 по сквозной нумерации → сезон и серия через TVDB |
| `[Group] Spy x Family S2 - 03 [1080p].mkv` | «Spy x Family», S02E03 |
| `1917.2019.1080p.WEB-DL.H264-FGT.mkv`, `2012.2009.BDRip.mkv` | название-число не путается с годом |

## Как это работает

1. **Номера серий** исправляются ещё до запроса метаданных. Учитываются только явные метки в имени (`S02E03`, «Серия 3», папка «Сезон 2»).
2. **Разбор имени.** Собственный парсер извлекает название (русское и оригинальное), год, сезон, серию, сквозной номер аниме, качество, группу релиза и озвучку.
3. **Поиск по источникам по очереди**, чтобы экономить квоты: TMDb → Кинопоиск (если в названии есть кириллица или язык русский) → TVDB (только сериалы) → OMDb. Поиск останавливается на первом уверенном совпадении.
4. **Консервативное сопоставление.** Совпадение оценивается по схожести названия, году и типу. Ниже порога (по умолчанию 0.75) плагин честно отвечает «не найдено», а не угадывает.
5. **Догрузка по ID.** Остальные источники запрашиваются по найденным ID. Поля собираются по приоритетам:
   - описания из Кинопоиска (если язык русский);
   - рейтинг IMDb через OMDb, рейтинг Rotten Tomatoes;
   - жанры и люди из TMDb;
   - данные серий из TVDB.
6. **ИИ (необязательно).** Вызывается, только если шаги 2–4 ничего не нашли. Ответ ИИ — подсказка: по нему снова выполняется поиск в источниках с тем же порогом. ID от модели не используются.

## Установка

1. Скачайте `smart-recognizer_<версия>.zip` (сборку — см. «Разработка») и распакуйте в папку плагинов Jellyfin, например `<data>/plugins/SmartRecognizer_0.1.0.0/`.
2. Перезапустите Jellyfin. В «Панель управления → Плагины» должен появиться **Smart Recognizer** со статусом Active.

## Настройка

### Ключи API

«Панель управления → Плагины → Smart Recognizer». Источник без ключа не используется.

| Источник | Где взять | Заметки |
|---|---|---|
| TMDb | themoviedb.org → Settings → API | бесплатно; подходит API-ключ v3 или токен доступа на чтение |
| Кинопоиск | kinopoisk.dev | **неофициальный** API с суточной квотой; при исчерпании источник отдыхает до следующих суток (UTC) |
| OMDb | omdbapi.com | бесплатно 1000 запросов в день; используется в основном для рейтингов по IMDb ID |
| TVDB | thetvdb.com (API v4) | платная подписка или лицензия проекта; PIN подписчика, если нужен |

### Библиотека — важно

В настройках каждой библиотеки («Управление библиотекой → ⋯ → Управление»):

- В разделах **«Загрузчики метаданных»** и **«Загрузчики изображений»** для фильмов, сериалов, сезонов и эпизодов поставьте **Smart Recognizer** первым.
- **Отключите или опустите вниз встроенные TheMovieDb и The Open Movie Database.** Jellyfin запускает все включённые провайдеры и берёт первое непустое значение каждого поля. Там, где Smart Recognizer сознательно ничего не нашёл, встроенный TMDb подставит свою, часто неверную, догадку.

### Если номера серий не совпадают

- Номера сезонов и серий исправляются автоматически (настройка «Исправлять номера сезонов и серий», включена по умолчанию).
- Для элементов, просканированных до установки плагина, выполните «Обновить метаданные → **Заменить все метаданные**».
- У аниме со сквозной нумерацией в одной папке сезон определяется по TVDB. Новый сезон Jellyfin создаёт при следующем обновлении сериала, поэтому иногда нужно обновить сериал второй раз.

### ИИ — запасной вариант

По умолчанию выключен. Поддерживаются два варианта:

- **Anthropic (Claude)** — нужен API-ключ. По умолчанию модель `claude-haiku-5-5`: для разбора имён хватает быстрой и недорогой модели.
- **OpenAI-совместимый API** — OpenAI, **Ollama**, LM Studio. Укажите адрес (например `http://ollama:11434/v1`) и модель. Для локальной модели ключ не нужен.

Ограничения и защита:

- **Суточный лимит запросов** (по умолчанию 500). Счётчик и кэш ответов хранятся в файле и переживают перезапуск сервера.
- **Приватность.** Модели отправляется только имя файла и две родительские папки. Если имена не должны покидать сервер, используйте локальную модель.

## Ограничения

- kinopoisk.dev — неофициальный API: проверьте условия использования перед продакшеном.
- Ключи API хранятся в XML-конфиге плагина в открытом виде (стандартная практика Jellyfin). В логи они не попадают.
- Имена вида «RU / EN» со слэшем на диске невозможны (`/` — разделитель пути). Поддерживаются варианты `RU (EN)`, `RU.EN.2008`, `RU _ EN`, `RU - EN` и `RU ／ EN`.

## Разработка

Требуется .NET 10 SDK.

Тесты (xUnit; парсер проверяется на корпусе реальных имён в `tests/.../TestData/release-names.json`):

```bash
dotnet test
```

Release-сборка:

```bash
dotnet build -c Release
```

Упаковка в ZIP для Jellyfin:

```bash
pip install jprm
```

```bash
jprm plugin build . --output=artifacts
```

Структура и правила — в [CLAUDE.md](CLAUDE.md). План и журнал реализации — `docs/plans/completed/`. Как Jellyfin 12.4 обрабатывает номера сезонов и серий — `docs/spikes/`.
