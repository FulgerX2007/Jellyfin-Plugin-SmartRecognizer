Smart Recognizer

Распознаёт фильмы и сериалы по имени файла и берёт метаданные из TMDb, Кинопоиска, OMDb и TVDB. Источник без API-ключа не используется. В настройках библиотеки поставьте «Smart Recognizer» выше встроенных источников, а встроенные TheMovieDb / The Open Movie Database лучше выключить: иначе они подставят свою догадку там, где плагин сознательно ничего не нашёл.

Источники

themoviedb.org → Settings → API. Бесплатно.
Неофициальный API с суточной квотой; когда квота кончается, источник отдыхает до следующих суток.

Распознавание

Ниже порога плагин честно отвечает «не найдено», вместо того чтобы угадывать. По умолчанию 0.75.

ИИ — запасной вариант

Вызывается только для имён, которые правила не смогли распознать. Ответ ИИ — лишь подсказка: плагин всё равно ищет фильм в источниках и применяет тот же порог уверенности.

Для разбора имён хватает быстрой недорогой модели, например claude-haiku-5-5.
Защита от расходов при сканировании большой библиотеки. Счётчик переживает перезапуск сервера.
⚠ Приватность: при облачном провайдере имя файла и до двух родительских папок отправляются во внешний сервис. Чтобы имена не покидали сервер, используйте локальную модель через OpenAI-совместимый API.
